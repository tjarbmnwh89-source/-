# Creator Starter AI

## Run locally
1. Install Node.js.
2. Run `npm install`
3. Create `.env` and set `GEMINI_API_KEY=...`
4. Run `npm start`
5. Open `http://localhost:3000`

## Deploy
Set the environment variable `GEMINI_API_KEY` in your hosting provider. Never put the real API key inside `public/index.html`.
